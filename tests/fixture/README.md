# Test fixture for the research skills

A small research folder and the three Context documents that go with it, for testing the kit's skills in Cowork before a reader's real notes are involved. The setup skill creates `rules.md`, `map.md` and `inbox.md` as Context documents from the reader's answers; `context-documents/` holds the three the test's answers should produce, for comparison. `research-folder/` is copied by hand into the connected folder after setup, so the check skills have something to find.

Four defects are deliberate, so the description check has something to find: `notes/Topic Note.md` is named for a topic rather than a claim and carries no `created` line; `notes/notes-should-lead-with-the-claim.md` is hard-wrapped where the convention says one paragraph per line; `map.md` lists an open thread, "why capture and filing are different", whose note does not exist; and `sources/simon-1971-designing-organizations/` is a folder holding only its lead note, which should be one flat file. The Simon note is also the one source nothing cites, which the check reports without calling it a fault.

The sources show one note at each level: Simon at `citation`, Ahrens at `minimal`, and `sources/example-2024-notes-that-last/` at `read`, a compound source with its original in `originals/` and its page-marked rendition in `renditions/`. That paper and its author are invented for the fixture, so its PDF can ship; its two quotes pass the quote check against the rendition, and `topics/what-makes-a-collection-useful.md` is a topic note citing it and Ahrens. `CLAUDE.md` at the folder root carries an instruction, because Cowork reads a connected folder's `CLAUDE.md` at the start of a task without being asked (the explainer says so under What the connected folder does and does not protect); it stays so a test run can see that happen.

The inbox holds four captures chosen to exercise each branch of the drain: one that belongs in an existing note, one that is a new idea, one that belongs to another binder, and one that is a source to read.
