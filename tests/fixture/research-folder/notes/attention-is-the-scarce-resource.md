source: Simon, Herbert. Designing Organizations for an Information-Rich World. 1971.

Attention is the scarce resource, not information. A wealth of information creates a poverty of attention, so a system for handling information has to be judged by how much attention it saves rather than how much information it stores.

This is why the kit keeps the description small: every sentence Claude reads at the start of a conversation is attention spent before the question is asked.
