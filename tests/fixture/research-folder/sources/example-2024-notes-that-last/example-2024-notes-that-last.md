BRIEF

An invented short paper arguing that a note survives only when later writing needs it, and that synthesis should come before collection.

SHORT ABSTRACT

The paper argues that notes are kept alive by use, not by storage. It makes two claims: a note no topic note cites has no reader, and each note added to a pile raises the cost of finding any one. It proposes writing one living note per topic first and letting sources earn fuller notes only when cited.

KEY POINTS

- **Use keeps a note alive:** a note nothing cites is read by no one but its author.
- **Piles cost more as they grow:** each addition raises the price of finding any single note.
- **Synthesis first:** one living note per topic, with sources raised only when that note cites them.

KEY QUOTES

    > "A note that no topic note cites has no reader but its author, and its author has moved on." (p. 1)
    > "If the answer is a folder of sources, the collection has been gathering rather than thinking." (p. 2)

WHY SAVED

It names the failure I keep falling into with my reading notes.
