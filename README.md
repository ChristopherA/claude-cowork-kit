# Claude Cowork Kit

Plain files that stay yours, and a Claude that knows them. This kit is for people who use the Claude desktop app with Cowork rather than Claude Code: a set of plugins that set up a notes project first, then, if you want them, projects for learning, your week, money and medical records, each kept as ordinary files in a folder on your own computer, with a short document beside them that explains why the kit is shaped as it is.

## Start here

1. In the Claude desktop app, open Customize, then Plugins. Choose **Add marketplace** and enter `ChristopherA/claude-cowork-kit`, then install the plugin shown as **Cowork Kit core**. If you would rather not add a marketplace, download `cowork-kit.plugin` from the [releases page](https://github.com/ChristopherA/claude-cowork-kit/releases) and add it with the upload option on the same page.
2. Start a task and say `set up the kit`. Claude asks two or three questions, hands you one block of text to paste into your account settings, and says which plugin to install next.
3. Read [the explainer](docs/claude-cowork-kit.md) before you connect a folder. It says what the connected folder does and does not protect, which is the one thing worth knowing in advance, and it walks the setup step by step.

Install one plugin at a time and run its setup before the next.

## What is in it

Six plugins: `cowork-kit`, the core, with the setup and twelve routines that work in any project; `pkm`, the notes project; and `learn`, `week`, `money` and `medical`, one per project, each with a setup skill that builds the project and hands back only what you must paste by hand. The explainer, `docs/claude-cowork-kit.md`, prints every block a setup hands back, so you can read it first or paste it yourself.

## Status

Release candidate. The notes plugin has had one run in Cowork; the core and the four project plugins have not run yet, and whether the phone app runs plugins is not yet confirmed. Anything the kit is still confirming is marked as such where it appears.

## For contributors

- `docs/` holds the explainer, the single source: the blocks in every built plugin are generated from it and never edited by hand. `docs/skill-capabilities.md` records what a Cowork skill can reach.
- `plugins/<name>/` is one directory per plugin: its skills (`skills/<skill>/SKILL.md`, with read-only `scripts/` where a skill runs code), its manifest and README, and the setup skill's `references/`, the last three generated by the build and committed so the tree serves as a marketplace (`.claude-plugin/marketplace.json` lists them).
- `build.py` checks every skill the way Cowork's upload does, generates the manifests, READMEs and setup references from the explainer in place (`--check` fails when they drift, or when a generated file is uncommitted in a git checkout), and writes each plugin as a `.plugin` file and each skill as a `.skill` file under `dist/`, which is not tracked.
- `template/` is a project plugin with the brackets left in, for a project the kit does not describe. `tests/fixture/` is a small notes folder and the project docs a setup run should produce.
